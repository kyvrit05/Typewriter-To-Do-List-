# ⌨️ Clackity

**Clackity** is a simple, minimalist to-do list inspired by the nostalgic look and feel of a classic typewriter.

The idea is intentionally simple: **type your task, tap it when you're done, and watch it get crossed out.** The project focuses on creating a distraction-free and satisfying way to keep track of everyday tasks.

## ✨ Features

* 📝 Add tasks to your to-do list
* ✅ Tap a task to mark it as completed
* ~~Cross out~~ completed tasks
* ⌨️ Minimal typewriter-inspired interface
* 🎯 Simple and distraction-free design

## 🛠️ Technologies Used

* **HTML**
* **Visual Studio Code (VS Code)**

## 🔨 The Process

I wanted to start with a small project that focused on the fundamentals of building an interactive webpage.

The project began with designing a simple typewriter-inspired interface and structuring the to-do list using HTML. I then focused on making the list interactive so that users could easily mark tasks as completed.

Rather than adding too many features from the beginning, I chose to keep the first version intentionally minimal and use it as a foundation for future improvements.

## 📚 What I Learned

Through building Clackity, I learned more about:

* Structuring a webpage using HTML
* Creating interactive elements
* Thinking about **user experience (UX)** even for a simple application
* Breaking a larger idea into smaller, manageable features
* Iterating on a project instead of trying to build everything at once

## 🚀 Future Improvements

There are several features I would like to explore in future versions:

* 📅 **Task dates** — record when each task was created
* ⏰ **Two-day reminder system** — if a task remains incomplete for more than two days, the system could remind the user to work on it
* 💾 **Persistent storage** — save tasks so they remain after closing or refreshing the page
* ✏️ **Edit tasks** — allow users to modify existing tasks
* 📱 **Responsive design** — improve the experience across different screen sizes

## 💭 Project Idea

Clackity started as a small experiment in creating something **simple, functional, and visually distinctive**.

Rather than building another feature-heavy productivity app, I wanted to explore how far a very small idea could go with the right interaction and design.

This project is also a starting point for experimenting with more web development concepts and gradually adding functionality as I learn.
